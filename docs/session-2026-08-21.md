### 3. 갤러리 워커 (`run_gallery_worker.py`)

Flask 내부 poller thread가 job을 `processing`으로 잡고 완료 못 하는 문제 반복 발생.
→ 해결책: `processing` 상태 job을 주기적으로 `queued`로 리셋 후 standalone worker 실행.

```bash
# stuck job 리셋
PATCH /gallery_jobs WHERE status=eq.processing → {status: queued, attempts: 0}

# 워커 실행
python3 -u run_gallery_worker.py
```

한신희 갤러리 작업 시 뚝딱이형 job은 별도 삭제 후 한신희 39개만 처리.
