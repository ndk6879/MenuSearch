## 작업 2: 이미지 파이프라인 자동 연동

### 문제
- step_images 추출은 `test_frame_extract.py`로만 수동 실행 가능
- 헤더 Analyze 버튼 → `/save-recipe` 저장 후 이미지가 자동으로 처리되지 않음

### 해결
- `/save-recipe` 엔드포인트에 비동기 이미지 처리 추가
- `/analyze-save` 엔드포인트에도 동일하게 적용
- 저장 즉시 응답 반환 → 백그라운드 스레드가 이미지 추출/업로드 처리
- 완료 후 Supabase `recipes.step_images` PATCH 업데이트

```python
threading.Thread(target=_bg_process_images_save, daemon=True).start()
```

## 작업 4: YouTube Shorts URL 지원

### 문제
- video ID 추출 regex가 `/shorts/VIDEO_ID` 형식 미지원
- `youtube.com/shorts/...` URL 입력 시 "videoId 추출 실패" 에러

### 해결
```python
# 변경 전
r"(?:v=|youtu\.be/)([A-Za-z0-9_-]{11})"
# 변경 후
r"(?:v=|youtu\.be/|shorts/)([A-Za-z0-9_-]{11})"
```
`youtube_automation.py` + `api_server.py` 두 곳 모두 적용.
