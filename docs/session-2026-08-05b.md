## 1. 재료 소스 추적 (ingredients_sources)

### 개요
각 재료의 용량이 어디서 왔는지 추적 — 크리에이터가 직접 명시한 양 vs Groq 추정

### Supabase 스키마 변경
```sql
ALTER TABLE recipes ADD COLUMN ingredients_sources text[] DEFAULT '{}';
```
`ingredients`, `ingredients_measured`와 인덱스 동기화. 소스 종류:
- `"고정댓글"` — 유튜브 고정댓글에 명시된 양
- `"더보기란"` — 영상 설명란에 명시된 양
- `"video_visual"` — 영상 화면에서 확인된 양
- `"video_audio"` — 음성에서 언급된 양
- `"subtitle"` — 자막에서 추출
- `"groq"` — Groq이 추정한 양 (기본값, UI에 배지 미표시)

### 파이프라인 변경 (youtube_automation.py)

**새 함수 `extract_confirmed_quantities_from_text(raw_text, source_name, ingredients)`**
- 고정댓글/더보기란 텍스트에서 알려진 재료의 명시적 용량 추출
- 반환: `{재료명: {"quantity": "2큰술", "source": "고정댓글"}}`

**`estimate_quantities_with_groq()` 시그니처 변경**
```python
# 이전
estimate_quantities_with_groq(dish_name, ingredients) → list[str]

# 이후
estimate_quantities_with_groq(dish_name, ingredients, servings="", confirmed=None) → list[dict]
# 반환: [{"text": "파스타 100g", "source": "groq"}, ...]
```

**Groq 프롬프트 개선:**
- `servings` (분량 기준) 전달 → Groq이 인분 수 인지
- 건파스타 1인분 = 80~100g 기준 명시 (이전: 150~200g으로 과다 추정)
- `[확인된 양: X]` 앵커 — 크리에이터 명시 양은 그대로, 나머지는 비율 맞춰 추정

**파이프라인 흐름:**
1. 텍스트 소스 분석 (고정댓글/더보기란) → confirmed 딕트 구성
2. `estimate_quantities_with_groq(name, ingredients, servings, confirmed)` 호출
3. 반환된 리스트에서 `text` → `ingredients_measured`, `source` → `ingredients_sources`로 분리 저장

### 프론트 표시 (App.js)
- `sortedData` useMemo에서 `ingredients_sources`도 인덱스 동기화 정렬
- 레시피 모달 RECIPE 섹션: 크리에이터 확인 양(groq 제외)에 파란 배지 표시
  - `고정댓글` → "댓글" / `더보기란` → "설명" / `video_visual` → "영상" 등
- CSS: `.recipe-ing-source-badge` — 파란(`#4a9eff`) 소형 라운드 배지

## 4. Gallery UI (레시피 모달 이미지 섹션)

### INSTRUCTION → INSTRUCTION + GALLERY 분리
- **INSTRUCTION**: 텍스트 step만 (이미지 제거)
- **GALLERY**: step_images 있는 레시피에만 표시, 4열 그리드

### Gallery 그리드
```css
.recipe-gallery-grid { grid-template-columns: repeat(4, 1fr); gap: 8px; }
.recipe-gallery-item { aspect-ratio: 1; border-radius: 8px; overflow: hidden; }
```
- 이미지 좌상단 원형 step 번호 배지
- hover 시 살짝 확대 (`transform: scale(1.04)`)

### Gallery 라이트박스
- 클릭 시 확대 — 이미지 + 하단 캡션 (step 번호 + 요리 순서 텍스트)
- `object-fit: contain` + `background: #000` → 전체 이미지 크롭 없이 표시
- 이미지 내 번인 자막과 캡션 분리: 캡션을 어두운 박스 하단에 배치
- 키보드 ← → 이동 / Escape 닫기
- 마우스 ‹ › 화살표 버튼 (이미지 좌우)

### step_images 처리 타이밍
- 레시피 저장 직후는 Gallery 비어있음
- 백그라운드 스레드에서 1~2분 후 Supabase에 업로드 완료 시 표시
