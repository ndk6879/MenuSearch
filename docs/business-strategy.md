# Findish 비즈니스 전략 및 수익모델

> 마지막 업데이트: 2026-07-02
> 이 문서는 창업자-AI 세션에서 논의·확정된 비즈니스 방향을 기록한다.

---

## 서비스 개요

**Findish** — 가지고 있는 재료로 만들 수 있는 레시피를 찾아주는 플랫폼.
현재 MVP 운영 중: https://menu-search.vercel.app/

요리 크리에이터들의 레시피를 아카이빙하고, 이커머스 제휴 수수료와 AI 구독 서비스로 수익화한다.

---

## 파트너십

- **미뇨끼 PD님**과 비즈니스 파트너 확정
- 수익 분배: 미뇨끼 7 : Findish 3
- 역할: 미뇨끼가 주변 요리 크리에이터 모집·소통 담당 → 초기 10명 이상 확보 예상
- 미뇨끼는 현재 Findish에 크리에이터로 등록된 유일한 사용자 (`creator:minyokki`)

## Phase별 실행 계획

### Phase 1 (현재 ~ 6개월): 이커머스 원툴

**목표:** 크리에이터 모집 + 유저 행동 데이터 축적. 수익보다 트래픽 우선.

| 항목 | 내용 |
|------|------|
| 수익 모델 | 쿠팡 파트너스 이커머스 수수료 단 하나 |
| 크리에이터 수익 | 100% (Findish 몫 없음) |
| 크리에이터 혜택 | 무료 아카이빙 + 미니 대시보드 |
| 연동 플랫폼 | 쿠팡만 (컬리/네이버/SSG는 Phase 2 이후) |
| 개발량 | 최소 |

**쿠팡 파트너스 운영 구조:**
- Findish 마스터 계정 1개로 운영 (크리에이터 개별 계정 아님)
- 링크에 `subId=creator_이름&recipeId=xxx` 파라미터 삽입
- 월말 쿠팡 대시보드 → subId별 수익 집계 → 크리에이터 계좌 이체 (초기 수기)
- 세금/사업자 처리는 7:3 전환 시점에 구축

**미니 대시보드 (Phase 1 최소 버전):**
- 크리에이터 전용 페이지에 숫자 3개만: 조회수 / 북마크 수 / 이커머스 링크 클릭 수
- 트렌드 그래프·SEO 제안 등 고도화는 Phase 3 B2B 구독 기능으로 이전

---

### Phase 2 (6 ~ 18개월): B2C AI 구독 서비스

**목표:** 유저 베이스 확보 후 구독 과금 시작.

**핵심 가치 제안 (메인):**
> AI 냉장고 파싱 — 냉장고 사진을 찍으면 재료를 자동 인식하고 만들 수 있는 레시피를 즉시 제안

**보조 구독 기능:**
- AI 커스텀 레시피 변환 (1인분 조정, 알레르기 재료 제거 등)
- 북마크 무제한
- 얼리 액세스 (크리에이터 유튜브 업로드 1~2주 전 레시피 선공개)
- 테마 필터 전체 해제 (다이어트, 재료 해치우기, 파티용 등)

**무료/유료 경계:**

| 기능 | 무료 | 유료 구독 |
|------|------|-----------|
| 재료 검색 | 무제한 | 무제한 |
| 북마크 | 5개 | 무제한 |
| AI 냉장고 파싱 | ✗ | ✓ |
| AI 커스텀 레시피 | ✗ | ✓ |
| 테마 필터 | 1~2개 | 전체 |
| Feed/커뮤니티 | 읽기만 | 작성 + 알림 |
| 얼리 액세스 | ✗ | ✓ |

> 재료 검색은 핵심 가치이므로 무료 개방. 북마크 5개 제한이 자연스러운 유료 전환 트리거.

**주의:** AI 냉장고 파싱은 Vision API 비용이 발생하므로 구독 가격 산정 시 API 호출 비용을 먼저 계산해야 한다.

**크리에이터 정산 전환:**
- B2C 구독 출시 시점에 7:3으로 전환 (달력 기준 아님, 마일스톤 기준)
- 창립 크리에이터(첫 N명): 출시 후에도 75% 영구 우대
- 온보딩 시 전환 조건 명시 필수 (계약서 또는 이용 약관)

**추가 수익 모델 (Phase 2):**
- 브랜드 스폰서드 슬롯: 재료 검색 결과 상단에 브랜드 레시피 카드 노출 (예: "닭가슴살+브로콜리" 검색 → [광고] 하림 레시피 상단 노출)

---

### Phase 3 (18개월+): 데이터 비즈니스 + IR

**목표:** 축적된 데이터를 자산화하고 투자 유치.

- 식재료 구매 전환 데이터 + 선호 레시피 데이터 → 식품 브랜드에 마케팅 인사이트 판매
- B2B 크리에이터 구독 (레시피 자동화, SEO 제안, 고급 대시보드)
- 투자설명회(IR) 및 대면 PT를 통한 스케일업
- 공동구매: 크리에이터 기존 공구 링크 연결 라이트 버전 검토 (Findish 운영 부담 없음)
- 컬리 / 네이버 쇼핑 / SSG닷컴 추가 연동 검토

## 크리에이터 인센티브 구조

### 금전적 혜택

| 시기 | 구조 | 비고 |
|------|------|------|
| Phase 1 | 이커머스 수수료 100% | Findish 몫 없음 |
| Phase 2+ (창립) | 이커머스 75% + 구독 수익 일부 | 영구 우대 |
| Phase 2+ (일반) | 이커머스 70% | 구독 출시 트리거로 전환 |

### 비금전적 혜택
- 무료 레시피 아카이빙 (유튜브 외 독립 채널)
- 유튜브 조회수 유입 증가
- 전용 URL (`findish.com/chef/이름`)
- 미니 대시보드 (Phase 1) → 고급 대시보드 (Phase 3)
