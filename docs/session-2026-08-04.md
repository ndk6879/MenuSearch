## 추가된 기능

### 1. ingredients_measured — 재료 용량 계량 (Groq)
- Gemini가 영상을 관찰해 재료 목록 확정 → Groq(llama-3.3-70b-versatile)이 용량 추정
- Gemini는 순수 관찰(hallucination 방지), Groq은 텍스트 기반 추론으로 역할 분리
- `ingredients`와 인덱스 동기화 필수 (i번째 재료의 용량 = ingredients_measured[i])
- Supabase `recipes` 테이블에 `ingredients_measured text[]` 컬럼 추가

### 2. tips — 크리에이터 팁 (Gemini)
- Gemini가 영상에서 크리에이터가 말하는 팁 추출
- 최소 3개, 최대 5개. 영상 팁 3개 미만이면 Gemini 지식으로 보충 (중복 제외)
- Supabase `recipes` 테이블에 `tips text[]` 컬럼 추가

### 3. servings — 분량 (Gemini)
- 영상에서 분량 감지 ("2인분", "4인분" 등)
- 감지 불가 시 재료량 기반 추정
- Supabase `recipes` 테이블에 `servings text` 컬럼 추가

### 4. tags — 분류 태그 (Gemini)
- 4개 카테고리에서 해당 태그 선택:

| 카테고리 | 값 |
|---------|-----|
| 분량 | "1인분", "2인분", "3~4인분", "파티용" |
| 음식 종류 | "밥", "면류", "파스타", "고기", "해산물", "샐러드", "국물요리" |
| 조리 특성 | "30분 이내", "초보 가능", "재료해치우기", "밀프랩/도시락", "에어프라이어", "오븐" |
| 상황 | "다이어트", "술안주", "단백질", "브런치", "야식", "아이반찬", "손님상" |

- Supabase `recipes` 테이블에 `tags text[]` 컬럼 추가

### 5. 하나의 영상에서 여러 요리 처리 (Multi-dish)
- 동일 재료로 다른 버전인 경우: 이름에 접미사 붙여 별도 객체로 분리
  - 예: "봉골레 파스타 (기본)", "봉골레 파스타 (사프란 버전)"
- 완전히 다른 요리인 경우: 별도 요리로 각각 추출

- Gemini 프롬프트: 재료를 영상에서 보이는 것만 기록 (hallucination 방지)

- `/analyze-save`, `/save-recipe` 엔드포인트: tips/servings/tags/ingredients_measured 포함

- `AnalyzePanel`에 `onSaveSuccess={refreshRecipes}` prop 전달
- 레시피 모달: 태그/분량 배지 추가 (업로더/날짜 아래, 영상 위)

### src/components/AnalyzePanel.js

## 버그 수정

| 버그 | 원인 | 수정 |
|-----|------|------|
| 덮어쓰기 실패 (unique constraint violation) | POST merge-duplicates는 PK 필요 | PATCH + url filter로 변경 |
| 저장 후 레시피 카드 미갱신 | App.js가 마운트 시 1회만 로드 | refreshRecipes 콜백 패턴 도입 |
| 서버 캐시로 새 코드 미반영 | 포트 8000 프로세스 재시작 필요 | kill → restart |
