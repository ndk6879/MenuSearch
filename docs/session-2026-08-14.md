## 3. 레시피 URL 링크화

### 배경 및 목적
크리에이터(미뇨끼 등)가 본인 유튜브 영상 더보기란에 레시피 링크를 직접 달 수 있도록.
예: `"자세한 레시피: https://menu-search.vercel.app/minyokki/cold-noodles"`
나중에 카카오톡 공유 기능으로도 확장 예정.

### URL 구조 결정
`/:creatorSlug/:recipeSlug` (예: `/minyokki/cold-pasta`)
- 한글 인코딩 문제 방지를 위해 영어 슬러그 사용
- Gemini로 레시피 이름 영어 번역 → 하이픈 슬러그 생성
- 같은 크리에이터 내 중복 슬러그는 video_id 앞 4자리 suffix로 처리

### Supabase 변경
```sql
ALTER TABLE recipes ADD COLUMN IF NOT EXISTS slug TEXT;
```
→ 실행 완료

### 백엔드 변경 (api_server.py)
- `_generate_slug(name, uploader, video_id)` 함수 추가 — Gemini로 번역, 실패 시 video_id[:8] fallback
- `_ensure_unique_slug()` 함수 추가 — uploader 내 중복 방지
- `/analyze-save`, `/save-recipe` 두 저장 경로 모두 slug 자동 생성 후 저장

### 프론트엔드 변경 (src/index.js, src/App.js)
- `/:slug/:recipeSlug` 라우트 추가
- `recipeSlug` 파라미터로 직접 접근 시 해당 레시피 모달 자동 오픈
- 카드 클릭 시 URL이 `/:slug/:recipeSlug` 형태로 변경
- 모달 닫기 시 `/:slug` 페이지로 복귀
- 모달 헤더에 🔗 링크 복사 버튼 추가 (slug 있을 때만 표시)
- Supabase select 쿼리에 `slug` 컬럼 추가

### 기존 레시피 일괄 슬러그 생성 (미완료)
- `scripts/generate_slugs.py` 작성
- Gemini로 50개씩 배치 번역 후 DB 업데이트
- **아직 실행 안 됨** → 다음 세션 시작 시 `python scripts/generate_slugs.py` 실행 필요
