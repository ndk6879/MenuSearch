## 주요 변경

### 1. Supabase Native Kakao OAuth 전환
**기존:** 카카오 로그인 버튼 → 카카오 페이지로 이동 → 앱으로 복귀 → Flask 백엔드에서 처리 (가짜 이메일/SHA256 방식)  
**변경:** `supabase.auth.signInWithOAuth({ provider: 'kakao' })` 한 줄로 교체. Supabase가 전부 처리.

**삭제된 코드:**
- `api_server.py` `/auth/kakao/exchange` 엔드포인트 (80줄)
- `App.js` 카카오 콜백 useEffect
- `KAKAO_REST_KEY` 환경변수
- `handleSocialLogout` 중복 함수

### 2. 로그인 모달 UX 재설계
**기존:** "크리에이터 로그인" 타이틀 + ID/PW 폼 + 카카오 버튼  
**변경:** 카카오 버튼 메인 / 크리에이터 로그인은 하단 작은 링크로 분리

### 3. 세션 관리 개선
**기존:** `getSession()` + `onAuthStateChange` 이중 호출  
**변경:** `onAuthStateChange`의 `INITIAL_SESSION` 이벤트 단독 처리

### 4. 토스트 메시지 추가
- 재방문 자동 로그인 시: "다시 오셨군요, [닉네임]님!"
- 신규 로그인 완료 시: "로그인됐어요, [닉네임]님!"

## 트러블슈팅

| 에러 | 원인 | 해결 |
|------|------|------|
| KOE205 | Supabase가 `account_email` 스코프 요청, 카카오에 미설정 | 비즈 앱 등록 후 이메일 필수 동의 활성화 |
| Client Secret 위치 | 카카오 콘솔 UI가 "보안" 탭 아님 | 앱 → 플랫폼 키 → REST API 키 → 클라이언트 시크릿 |
| Redirect URI 위치 | 카카오 로그인 → 일반 탭이 아님 | 앱 → 플랫폼 키 → REST API 키 → 로그인 리다이렉트 URI |
