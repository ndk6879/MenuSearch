## 2. 태그 필터링 시스템

### 필터 드롭다운 (전체 메뉴 헤더)
4개 카테고리 드롭다운 — 세프 전체 옆에 배치:

| 드롭다운 | 태그 목록 |
|---------|---------|
| 분량 | 1인분, 2인분, 3~4인분, 파티용 |
| 음식 종류 | 파스타, 면류, 밥, 고기, 해산물, 샐러드, 국물요리 |
| 조리 특성 | 30분 이내, 초보 가능, 재료해치우기, 밀프랩/도시락, 에어프라이어, 오븐 |
| 상황 | 다이어트, 술안주, 단백질, 브런치, 야식, 아이반찬, 손님상 |

- 필터링 방식: **AND strict** (모두 선택된 카테고리에 해당하는 레시피만)
- 선택 시 드롭다운 텍스트 bold 처리

### 레시피 카드 태그 배지
- 위치: 썸네일 이미지 좌하단 오버레이
- 해당 레시피의 모든 태그를 반투명 pill로 표시
- 클릭 시 해당 카테고리 드롭다운 필터 자동 적용
- `TAG_GROUPS`로 카테고리 판별 → 맞는 state setter 호출

### 구현 구조 (App.js)
```js
const [selectedServings, setSelectedServings] = useState("전체");

  cookStyle: { label: '조리 특성', tags: ['30분 이내','초보 가능','재료해치우기','밀프랩/도시락','에어프라이어','오븐'] },
  situation: { label: '상황',     tags: ['다이어트','술안주','단백질','브런치','야식','아이반찬','손님상'] },
};
```
