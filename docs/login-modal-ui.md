# 로그인 모달 UI

## 최종 구조 (2026-06 기준)

```
┌─────────────────────────────┐
│  크리에이터 로그인              │  ← 타이틀
│                             │
│  아이디  [_________________] │  ← 크리에이터 폼 (메인, 항상 노출)
│  비밀번호 [_________________] │
│  [       로그인       ]      │  ← 보라색 (#4f46e5) 버튼
│                             │
│  ─────────── 또는 ─────────  │  ← 구분선
│                             │
│  [🟡 카카오로 로그인] [구글로 로그인] │  ← 소셜 버튼 (나란히)
└─────────────────────────────┘
```

## 디자인 결정 사항

### 레이아웃 순서
- **크리에이터 폼이 위** (메인), 소셜 버튼이 아래 (보조)
- 이유: Findish는 현재 크리에이터 중심 서비스. 소셜 로그인은 일반 사용자용 보조 옵션.
- Musinsa 로그인 화면과 동일한 패턴 (폼 위, 소셜 아래)

### 소셜 버튼 배치
- 두 버튼을 **가로로 나란히** (flex-direction: row, flex: 1 each)
- 이유: 세로 배치 시 모달 너비에 비해 버튼이 너무 커 보이고 빈 공간이 어색함

### 카카오 버튼 스타일
- **노란 배경** (`#FEE500`) + 검정 말풍선 아이콘
- 이유: 한국 사용자에게 가장 익숙한 카카오 로그인 버튼 형태 (쿠팡, 배민 등 동일)
- Simple Icons의 KakaoTalk 앱 아이콘(둥근 사각형)은 현업 로그인 버튼에서 잘 쓰이지 않음

### 구글 버튼 스타일
- **아웃라인** (테두리만, 배경 투명) + Google 컬러 G 아이콘
- 이유: 카카오와 색상 충돌 없이 통일성 유지

### Coming Soon 문구
- 제거됨. 소셜 로그인이 실제로 동작하므로 불필요.
- 이전 버전에 있던 "현재 크리에이터 전용" 안내 박스도 제거.

### 크리에이터 토글 버튼
- 제거됨. 이전엔 소셜이 메인이고 크리에이터 폼이 숨겨져 있었으나,
  레이아웃 역전 후 폼이 항상 노출되므로 토글 불필요.

## 관련 CSS 클래스 (src/index.css)

| 클래스 | 용도 |
|--------|------|
| `.login-modal` | 모달 내부 컨테이너 (min-width: 300px) |
| `.login-modal-title` | "크리에이터 로그인" 타이틀 |
| `.login-social-group` | 소셜 버튼 가로 배치 컨테이너 (flex row, gap 8px) |
| `.social-login-btn` | 소셜 버튼 공통 스타일 (flex: 1, padding, border-radius) |
| `.kakao-btn` | 카카오 전용 — 노란 배경, 검정 텍스트 |
| `.google-btn` | 구글 전용 — 아웃라인, 라이트/다크 모드 대응 |
| `.login-divider` | "또는" 구분선 (flex + ::before/::after 라인) |
| `.login-submit-btn` | 크리에이터 로그인 버튼 (보라색 #4f46e5) |
