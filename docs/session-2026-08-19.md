### 4. 완성 요리 이미지 기능 (`_find_final_dish_override`)
갤러리 마지막을 완성된 요리 사진으로 마무리하는 기능.

**흐름:**
1. 마지막 step 이미지 → `_is_final_dish()` YES/NO
2. YES → 그대로 (추가 없음)
3. NO → 마지막 step `tss[0]` 이후 ~ 영상 끝에서 ffmpeg 6~10장 추출 → `_select_best_final_dish_frame()`
4. 결과 → `step_images["dish_final"]`로 저장

**중요 버그 수정:** 처음엔 `tss[-1]` 사용 → 탐색 구간이 2.3초로 너무 좁아짐 → `tss[0]`으로 수정

**stream_url 재획득:** 긴 갤러리 작업 후 HLS URL 만료 대비
